# RTOS_2_71_Luis
El repositorio de Luis Carlos Guerrero Velázquez de RTOS \
Para compilar y subir este codigo se requiere utilizar la implementacion de arduino y freertos en platformio para la familia de microcontroladores CH32V, instrucciones aquí: https://github.com/Community-PIO-CH32V/ArduinoCore-CH32V \
El hardware utilizado es la placa de evaluacion CH32Vx03C-R0-1v0 del microcontrolador CH32V203C8T6 utilizando el oscilador externo para trabajar a 144Mhz
